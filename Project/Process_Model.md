The Incremental Model



**Justification**



Dependencies: Hierarchy is very important; teams and players need to be registered first before the matches can be scheduled. Hence, the incremental model helps build a strong base and then be able to add new features.



Stages of complexity: After the main registration is successfully implemented, the complex real-time match scheduling can be developed as add-ons.



Early Customer feedback: As early stages of the software are rolled out, we can get early customer feedback, making it easier to understand what the users want.



**Major Drawbacks and Mitigation**

Drawback: it would require major upfront detailing

&#x09;Mitigation: we would have to be very forward-thinking with the structure of the database 	such that future data of the scheduling do not make us rebuild the early foundation of the 	project



Drawback: Integration of increments may increase costs and time of development

&#x09;Mitigation: after each increment, we would need to be very rigorous with the integration 	testing and have the foresight of future increments when we make the previous increments
